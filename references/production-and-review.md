# 科学内容、动画与视觉的制作流程

## 1. 把“想展示什么”变成可核验的方案

先提炼一条观众应理解的因果链，以及每个环节对应的可见证据。
例如：输入/激励 → 传输 → 相互作用 → 状态改变 → 结果/后续循环。
不要从建模对象清单倒推研究结论。只在关键物理含义缺失时集中询问；装饰细节可自行处理。

建立参数表：名称、数值/单位、来源、适用条件、真实比例或示意比例、是否冻结。
世界单位与显示单位分开；明确支承面、参考坐标、运动正方向、实际过程时间与演示时间。
“开口大所以流量大”“颜色变暗所以温度已被求解”等推论没有数据时不能成立。
若压薄/消失/相变会造成物质凭空消失的误读，补充去向或明确非定量示意；不编造守恒结果。

分镜表用“时间/帧段、工艺状态、运动对象、镜头目的、字幕/小框、核验点”组织。
终点可为过程完成、循环继续、结果对比或实验结论；由研究任务决定，不强制所有视频循环结尾。

## 2. 基础几何先验证空间关系

先做少量核心部件并用中性材质检查：
- 尺寸与单位，入口/出口/连接面，支承高度和间隙；
- 运动机构的实际自由度，父子关系及局部/世界坐标；
- 核心接触区在主镜头是否可见；
- 是否遗漏会改变机理理解的必要连接，例如轴支架或真实通道。

命名按语义与角色，便于只改特定子系统。复杂外观不能替代正确接触与流路。
先完成一个代表过程，再复制/推广到多阶段、多层或其他路径；不要同时调几何、物理叙事、镜头、配色。

## 3. 选择最低足够复杂度的动画实现

| 表达需要 | 可优先采用 | 应说明的边界 |
|---|---|---|
| 刚体移动、旋转、机械跟随 | Keyframe、Constraint、Driver | 用世界变换核对运动主体，注意父级双重变换 |
| 平滑形貌转变、局部增厚/减薄 | Shape Key、Curve、GN | 与执行机构位置同步，不能整段突然换形 |
| 轨迹生成、逐段增长、多实例 | Curve/GN、参数化网格 | 闭环接缝、起终点、支承面与接触关系 |
| 液态/固态与冷却示意 | 材质参数随距离/时间渐变 | 状态表达，不冒充温度求解 |
| 轻微蒸气、扩散/捕集示意 | 少量软粒子、低成本shader/mesh | 固定随机种子、不同相位；明确是定性过程 |
| 有验证依据的流体/热/应力场 | 导入实验/仿真结果，或受控求解 | 记录求解模型、边界条件与验证；成本另评估 |

不是所有液体题材都需要Mantaflow/CFD；若真实自由液面、飞溅或定量场是研究目标，则不能用几何假动画冒充求解。
随机运动应可重复，按时间/帧确定状态；跳帧渲染仍一致，或先完成必要缓存。不要用“每渲一帧累加随机数”的方式导致续渲不同。

若涉及分子轨迹、仿真场、复杂参数化/晶格或批量生成，先按[开源选型](open-source-selection.md)选择领域工具；数据→单位/时间适配→原生属性→样式的接口，以及可复用节点/模块约定见[开源方法](open-source-patterns.md)。不为普通局部修订引入整套依赖。

## 4. 工艺状态模型先于长动画

阶段可能包括：就位、激励/供给、增长/作用、关闭输入、残余过程完成、抬升/回位、下一轮。
先制定状态转移，再让几何、显隐、粒子、标签、相机读取同一状态。停止输入不意味着所有残余物瞬间消失；是否有滞后由机理决定。

用真实关系核对速度和距离，例如适用时 `v=ωR`、执行器后置弧长对应的延迟、层高相对于支承面。
不同阶段速度有设计依据时保留；若只是挤时间导致难以理解，应调整阶段时长，不冒称工艺规律。
多层/多周期应核对每轮参考面、起点、方向与门控，不能只检第一轮。相机跟随可能掩盖路径错误，要读Action/F-Curve/Driver求值。

## 5. 镜头与同步小框

常用叙事是“整体定位 → 局部过程 → 整体结果/继续”，但不强制三段；每个镜头应回答一个研究问题。
镜头避免大设备遮住接触区，必要时轻微下移/侧移或降低机构视觉权重；不能用新机位遮掩错误机理。
检查Location、Rotation/Target和Lens共同连续，连续镜头尽量无意外加速/停顿；技术性剪切可用于确有需要的比较镜头。
辅助观察相机可以用于审核，但不得把辅助角度截图说成正式主镜头效果，更不能意外保存覆盖Camera_Main。

小框只放主画面不易看清的因果关系。支持纵剖面、局部展开、放大图；标明非同比例/机理示意。
从主场景状态派生层状态、供给、执行器位置、粒子源面、厚度及淡出，避免时间不同步。
可采用独立Collection、相机固定平面或compositor；保持统一投影平面，避免视觉叠层产生虚假越界。

**信息的视觉语言必须不同：**
- 实线轮廓代表结构；
- 少量短箭头代表总体趋势；
- 离散点/雾点代表悬浮物；
- 紧贴壁面的薄膜代表附着物；
- 颜色渐变代表定义好的状态，不兼任未经说明的温度读数。

不能把固定长轨道当作随机扩散；未建立相应机理时，不能让已附着物无故转为输运粒子。若研究过程本就包含脱附、再悬浮或冲刷，需明确其触发与状态转换。
需要边界约束时，审核粒子**完整轮廓**、亮段宽度、箭头尖端与通道，包括接近壁面/狭缝/出口及循环重置。
粒子尺寸/alpha调整可能影响轮廓边界与文字遮挡，必须重新查受影响范围；报告采样帧/子帧、阈值、误差裕量，有限采样不等于连续数学证明。

## 6. 材质、灯光和背景单独精修

先确定层级：研究主体/关键物理现象最清楚，设备支撑适度弱化，背景最低存在感。
优先用明度、粗糙度、高光形态和结构轮廓区分，不依赖颜色单独编码。液体不能高光过曝到丢失形状。
背景与照明分开：只换相机看到的背景时，保持环境照明/反射、曝光、相机、材质和帧一致，才是可比较的A/B/C候选。
如果World同时影响照明，改变World色不再是“只换背景”；改用camera-ray分支、背景板或合成背景，并核对非背景区域差异。
使用现有稳定色彩管理，检查高光细节与阴影；不为了“高级”添加夸张发光、彩灯或工业背景。
会议/PPT应在实际嵌入尺寸检查文字、羽流、薄膜与主次关系，不能只在小框放大截图上验收可读性。

## 7. 多语言保持单一场景来源

有双语需求时，用统一文本ID与CN/EN映射，或者两套文字Collection；动画/几何/材质是共同源。
允许单条长英文缩放或轻微位置适配，记录差异白名单；优先局部适配并保持已冻结的小框布局。新建且布局未冻结时可合理重新排版。
动态阶段文字必须全阶段翻译并检查，不能只检查某层某帧。字体按项目许可打包/归档，不能假定目标电脑有相同系统字体。
验证共同内容：对象/动画/材质身份 + 同帧图像；图像mask只覆盖实际文字及抗锯齿余量，不能把整个HUD/inset遮掉以掩盖动态差异。
语言区内仍单独核对粒子压字、溢出、字号、术语和信息关系；记录允许的微小栅格误差，不虚报逐像素相同。

## 8. 每轮修改与核验闭环

先列一份简短改动表：源文件、可改对象/属性、锁定对象/属性、输出版本、代表帧、成功判据。
优先小补丁，保存可靠checkpoint，再做检查。图像已有且内容/渲染来源未变时可复用，不能反复重建同一轮。
至少按涉及的问题检查：
- 数值：尺寸、间隙、支承面、世界变换、路径闭合、方向、速度和对象显隐；
- 静帧：全景、局部、开始/中间/结束、关键相变或接触；
- 动态：相邻帧及短片，查流动、增长连续、门控、标签时序、镜头与淡出；
- 保持性：锁定内容前后指纹/定义对比，必要时非改动区域像素比对。

复杂场景的指纹应覆盖网格/Shape Key/GN、Action及Driver、Constraint、父子与可见性、材质/World/相机；不要只比对象数量或少量Transform就宣称“所有内容未变”。
每项注明实现完成/数值通过/已看图/已播放/用户确认，不能合并为一个“完成”。
冻结后发现问题，按影响范围定位帧段；只在授权范围修正。可以用A机理错误、B观感问题、C轻微问题分类，但不隐瞒已知缺陷。
